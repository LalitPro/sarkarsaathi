# Sarkar Saathi (सरकार साथी) 🚀
> **"SarkarSaathi – Government Schemes aur Documents ka Smart AI Guide."**

SarkarSaathi is a state-of-the-art, AI-powered citizen assistance and government guidance platform built for the **Build For Good 2026 Hackathon**. It aims to simplify the discovery, eligibility checking, and application process for Indian government schemes and citizens' documents.

---

## 🛠️ Technology Stack
- **Framework**: React.js 19
- **Build Tool**: Vite
- **Styling**: Tailwind CSS v4 (with PostCSS)
- **Icons**: Lucide React & FontAwesome
- **Data Persistence**: LocalStorage with optional Firebase Realtime Database Sync

---

## ✨ Core Features

1. **Smart Scheme Finder**: Filter schemes by demographic parameters (Age, State, Gender, Income, Category, and Occupation) with real-time eligibility status checks.
2. **Document Sahayak**: Get step-by-step application instructions, processing times, fees, application links, and dynamic dependency checker alerts for core documents.
3. **Problem Solver**: Search for common application problems (such as misspelled details, lost cards, etc.) to get potential reasons, required fixes, and next steps checklists.
4. **AI Government Assistant**: A context-aware conversational chatbot that greets users by name/demographics and answers questions regarding schemes, docs, or issues.
5. **Eligibility Booster (पात्रता बूस्टर)**: Identifies missing documents that, if obtained, would unlock the highest number of new government schemes for the user.
6. **Admin Panel CMS**: Secure data console (password: `admin123`) to Add/Edit/Delete schemes, documents, and problems, complete with live cloud database syncing options.

## 🚀 Running Locally

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Start Dev Server**:
   ```bash
   npm run dev
   ```

3. **Build Production Bundle**:
   ```bash
   npm run build
   ```
